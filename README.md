# Keystone Lite Landscaping: free one-page landscaping website template

A fast, accessible, single-page HTML/CSS site for a landscaping or lawn care company:
weekly mowing, landscape design, patios and hardscaping, irrigation and seasonal clean-ups.
No framework, no build step: open `index.html`, change the words, upload the folder.

**Live preview:** https://stephen-psaradellis.github.io/landscaping-website-template/

Running a plumbing or HVAC business instead? The same layout with a trades
theme is [Keystone Lite](https://github.com/Stephen-Psaradellis/plumber-website-template). A dental
practice? [Keystone Lite Dental](https://github.com/Stephen-Psaradellis/dentist-website-template).
A cleaning service? [Keystone Lite Cleaning](https://github.com/Stephen-Psaradellis/cleaning-website-template).
A law firm or solo attorney? [Keystone Lite Legal](https://github.com/Stephen-Psaradellis/law-firm-website-template).
A roofing company? [Keystone Lite Roofing](https://github.com/Stephen-Psaradellis/roofing-website-template).
An electrical contractor? [Keystone Lite Electrician](https://github.com/Stephen-Psaradellis/electrician-website-template).

## What you get (free, MIT)

- One home page with hero, six landscaping services with example prices, a three-step
  visit-quote-build process, why us, a seasonal booking banner, customer reviews, service
  area and a book-a-site-visit call to action
- HomeAndConstructionBusiness JSON-LD, so search engines read the business as a local contractor
- Sticky call bar on phones, so a customer is one tap from ringing you
- Light and dark mode (follows the visitor's system, plus a header toggle)
- LocalBusiness JSON-LD, Open Graph and Twitter Card tags, canonical URL
- Accessibility basics: skip link, landmarks, visible focus, reduced-motion support
- Retheme the whole site by editing the variables at the top of `assets/css/style.css`
- One small script (`assets/js/main.js`) for the mobile menu and the dark-mode toggle

## Quick start

1. Download this repository (Code > Download ZIP) and unzip it.
2. Open `index.html` and replace the business name, phone number (`tel:` links too),
   service area, hours, services and reviews with your own.
3. Update the JSON-LD block in `<head>` with the same details, and point the
   canonical / Open Graph URLs at your domain.
4. Upload the folder to any static host: GitHub Pages, Netlify, Cloudflare Pages or
   plain shared hosting.
